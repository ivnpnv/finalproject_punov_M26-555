# ValutaTrade Hub

Учебное консольное приложение для управления виртуальным портфелем фиатных и криптовалют. Пользователь регистрируется, входит в систему, покупает и продаёт валюту, просматривает балансы и курсы.

**Core Service** отвечает за пользователей, кошельки и операции. **Parser Service** получает котировки из CoinGecko и ExchangeRate-API, сохраняет историю и обновляет локальный кэш. Core читает кэш без сетевых запросов.

## Установка

Нужны Python 3.12 или новее, Git и uv.

py -3.12 -m pip install uv
git clone https://github.com/ivnpnv/finalproject_punov_M26-555.git
cd finalproject_punov_M26-555
py -3.12 -m uv sync --locked

## Ключи API

Получите ключ в личном кабинете https://www.exchangerate-api.com/ и задайте переменную окружения в той же сессии PowerShell, из которой запускаете приложение:

$env:EXCHANGERATE_API_KEY = "ВАШ_API_КЛЮЧ"


Для CoinGecko используется публичный endpoint. Если у вас есть Demo API key, его можно передать отдельно:

$env:COINGECKO_API_KEY = "ВАШ_DEMO_КЛЮЧ"

## Запуск и команды

py -3.12 -m uv run valutatrade

```text
help
update-rates
register --username alice --password 1234
login --username alice --password 1234
show-portfolio
buy --currency BTC --amount 0.05
sell --currency BTC --amount 0.01
show-portfolio --base USD
get-rate --from BTC --to USD
show-rates
show-rates --top 2
show-rates --currency RUB
show-rates --currency BTC --base EUR
exit
```

| Команда | Назначение |
| --- | --- |
| `register --username NAME --password PASSWORD` | Создать пользователя и пустой портфель |
| `login --username NAME --password PASSWORD` | Войти в текущей сессии приложения |
| `show-portfolio [--base USD]` | Показать кошельки и общую оценку портфеля |
| `buy --currency BTC --amount 0.05` | Увеличить баланс валютного кошелька, создав его при необходимости |
| `sell --currency BTC --amount 0.01` | Уменьшить баланс при достаточном остатке |
| `get-rate --from BTC --to USD` | Показать курс, обратный курс и время котировки |
| `update-rates [--source coingecko\|exchangerate]` | Обновить оба источника или только выбранный |
| `show-rates [--currency BTC] [--top 2] [--base USD]` | Показать таблицу из кэша, отфильтровать и пересчитать курсы |
| `help`, `COMMAND --help`, `exit` | Справка и выход |

Поддерживаются USD, EUR, GBP, RUB, BTC, ETH и SOL. Коды вводятся заглавными латинскими буквами. Сумма - конечное положительное число. Покупка, продажа и просмотр портфеля требуют входа; просмотр и обновление курсов доступны без него. После выхода из приложения нужно войти заново.

Выбрана упрощённая модель торговли: `buy` увеличивает баланс покупаемой валюты, `sell` уменьшает баланс продаваемой. Стоимость покупки и выручка в USD выводятся как оценочные; отдельного списания или зачисления на USD-кошелёк нет. При регистрации портфель пуст, стартовый баланс USD не требуется.

`--top` выбирает самые дорогие криптовалюты по цене одной единицы, а не по капитализации.

## Кэш, история и TTL

Данные создаются в `data/` по мере регистрации и обновления котировок:

- `users.json` - пользователи, хеши, соли и ISO-даты регистрации;
- `portfolios.json` - портфели и балансы кошельков;
- `rates.json` - последний срез: словарь `pairs` с парами вроде `BTC_USD`, полями `rate`, `updated_at`, `source` и общим `last_refresh`;
- `exchange_rates.json` - массив исторических измерений с ID из пары и UTC-времени, источником и метаданными запроса.

CoinGecko запрашивает BTC, ETH и SOL одним запросом по ID монет. ExchangeRate-API запрашивает курсы относительно USD; значения обращаются, чтобы сохранить направление `EUR_USD`, `GBP_USD`, `RUB_USD`. Обратные и кросс-курсы Core рассчитывает через USD.

Повторное измерение с теми же парой и временем не дублирует историю. Более старое измерение не заменяет новый курс. Запись каждого JSON выполняется атомарно через временный файл и замену.

Возраст считается от времени котировки у источника, а не от времени запроса. `get-rate`, сделки и оценка портфеля отклоняют отсутствующие или устаревшие котировки и предлагают `update-rates`. `show-rates` позволяет просмотреть старые значения с явной отметкой «устарел».

Источник может возвращать котировки суточной давности. При TTL 300 секунд повторный запрос не сделает такую котировку свежей. Для учебной работы с суточными данными можно явно установить `rates_ttl_seconds = 86400` и перезапустить приложение. Это общий порог, который действует и на криптовалюты. В демонстрации используется именно этот порог; в проекте по умолчанию сохранены 300 секунд.

## Parser Service

Внутри интерактивного CLI:

update-rates
update-rates --source coingecko
update-rates --source exchangerate

Отдельный процесс для однократного обновления:

py -3.12 -m uv run valutatrade-parser --once

Периодическое обновление с паузой в секундах после завершения предыдущего:

py -3.12 -m uv run valutatrade-parser --interval 3600


Остановка: `Ctrl+C`. Интервал выбирайте с учётом лимита своего API-тарифа. Если один источник недоступен, данные другого сохраняются, а прежние котировки неуспешного источника остаются в кэше. При полном отказе источников файлы не обновляются.

Списки валют, соответствие тикеров ID CoinGecko, URL, базовая валюта запросов, таймаут и интервал находятся в `parser_service/config.py`. Общие пути, TTL и параметры логирования - в `[tool.valutatrade]`.

## Логирование и проверка качества

`@log_action` на `buy` и `sell` записывает успешные сделки и ошибки в `logs/actions.log`: пользователь, операция, валюта, сумма, курс, результат и изменение баланса. Исключения после записи пробрасываются в CLI. Ход обновления и ошибки источников записываются отдельно в `logs/parser.log`.

По умолчанию используется строковый формат с уровнем INFO. Ротация - при достижении 1 МиБ, сохраняются три резервных файла. Эти параметры можно изменить в `pyproject.toml`.

Сборка создаёт wheel и исходный архив в `dist/`. Каталоги данных, логов, окружения, кэш Ruff, `.env` и записи `*.cast` исключены из Git.
